# math-teacher-yemen

واجهة أولية عربية لمساعد معلم الرياضيات المنهج اليمني.

المميزات الحالية:
- لوحة تحكم عربية RTL
- منشئ اختبارات
- معاينة وطباعة
- بنك أسئلة
- خطط تدريس
- إدارة الصف
- لوحة مفاتيح رياضية
- دعم الهاتف المحمول

## التشغيل محليًا

npm install
npm run dev

## إنشاء نسخة إنتاجية

npm run build
